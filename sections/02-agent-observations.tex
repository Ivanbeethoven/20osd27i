\subsection{Observed requests in coding-agent runs}
\label{sec:agent-observations}

\paragraph{Capture.}
We reanalyzed eight SWE-bench Verified task runs~\cite{swebench2024}.
All used the same harness configured for \code{deepseek-v4-flash}.
Three runs had a broader investigation
and testing prompt and a 30-minute budget; all finished earlier.
Each base-commit checkout used an instrumented passthrough file system
on Ubuntu 24.04 under WSL. Instrumentation recorded requests reaching
FUSE handlers.

The capture contains 1,138,884 requests across all eight runs.
Counts include all statuses, setup, and teardown.
Pooled statistics weight requests equally rather than tasks. The companion
workload record retains instrumentation versions, per-task counts, and
source-validation details.

\paragraph{Metadata traffic.}
Six metadata methods (\code{lookup}, \code{getattr}, \code{getxattr},
\code{readdirplus}, \code{opendir}, and \code{releasedir}) accounted for
57.3\% of all calls (Figure~\ref{fig:agent-fuse-combined}(a)).
The Other category contains methods outside
these six and read/write. Among successful events, the metadata share
was 45.8\%, showing the contribution of unsuccessful probes.
Across individual tasks, all-status shares ranged from 39.6\% in SymPy
to 65.4\% in Django. Read calls outnumbered writes by 4.87:1 overall;
per-task ratios ranged from 3.12:1 to 42.7:1.

\paragraph{Request sizes.}
All 120,434 reads and 24,712 writes succeeded.
Reads ranged from 4 to 128 KiB, with a median of 12 KiB.
Writes ranged from one byte to 128 KiB, with a median of 4 KiB.
Requests of at most 4 KiB accounted for 37.0\% of reads and
51.0\% of writes. The interval $(4,64]$ KiB contained a further
36.3\% of reads and 43.0\% of writes
(Figure~\ref{fig:agent-fuse-combined}(b)).
This mixture calls for measuring how fetching and object formation
transform requests before selecting storage granularity.

\paragraph{Variation across tasks and time.}
Tasks generated 8,542--634,726 calls over capture spans of
42.7--556.1 seconds. Astropy contributed 55.7\% of all requests,
so the pooled distributions describe recorded traffic rather than
an equally weighted typical task.
The busiest 10\% of one-second windows contained 47.4--83.7\% of each
task's calls (Figure~\ref{fig:agent-fuse-combined}(c)). Windows include idle
and final partial windows; the number selected is rounded up per task.
These differences favor retaining per-task mixes and timing in replay.

\paragraph{Measurement limits.}
The capture contains 872,519 successful, 253,669 error, and 12,696
unpaired events. Errors are lookup and attribute probes except for 14
\code{rmdir} calls; missing errno values prevent finer attribution.
Unpaired events are \code{forget} and \code{destroy} records. Each task
was observed once, and task-grading success was not established.
The traces characterize requests reaching the passthrough file system.
They do not establish remote latency, ML access patterns, cross-task
sharing, sparse mutation, or \sys performance.
