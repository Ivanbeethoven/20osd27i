\title{\sysname: Delta-Based Multi-Agent Workspaces with Packed Metadata\\
and Variable-Granularity Object Storage}
\author{Internal research draft\\26 October 2026}
\date{}
\maketitle
\begin{abstract}
Agent services need private working state and repeated access to shared
repositories, dependencies, and datasets. Reusing file contents leaves
the costs of representing edits, querying shared metadata, and serving
partial reads. We present \sys, an object-backed distributed file system
with three independently optional mechanisms. Delta-Based Workspaces
retain private namespace records and data-range mappings over a pinned
baseline, preserving references to unchanged data. Packed Metadata
organizes a published read-only directory version into authenticated
pages that co-locate names, common attributes, and data locators. These
pages serve supported queries outside the mutable metadata database,
targeting stable small-file collections shared by many readers.
Variable-Granularity Object Storage separates client object formation
from backend encoding and verification. A co-designed RustFS extension
accepts coding-block-size hints and persists each object's effective
layout for subsequent reads and repair. A native workspace can fork
without packing, and a packed version can serve independent read-only
access. We describe the
representations and update protocols, and characterize 1,138,884 FUSE
requests from eight coding-agent runs to establish access patterns
for evaluation.
\end{abstract}
