\author{Internal research draft\\26 October 2026}
\date{}
\maketitle
\begin{abstract}
Agent tasks need private working state while reusing source trees,
dependencies, and datasets. Sharing those bytes avoids duplication, but
leaves the cost of serving metadata and partial reads.
\sys addresses these costs through three independently optional mechanisms.
Delta-Based Workspaces retain private namespace changes and data-range
mappings over a shared baseline. Packed Metadata serves a selected,
previously packed read-only subtree through indexed object pages that
co-locate names, attributes, and data locators. It targets stable
collections of many small files, including training datasets reused across
machine-learning experiments. Variable-Granularity Object Storage separates
client object formation from backend encoding and verification units.
Each mechanism has a distinct cost: retaining private changes, building
and publishing packed versions, or fetching and verifying storage units.
We describe their representations, update protocols, and implementation
limits. A study of 1,138,884 FUSE requests from eight coding-agent runs
finds substantial metadata traffic, mixed request sizes, and bursty access.
The planned evaluation tests whether savings repay preparation and
retention costs, then examines their effect on fork, migration, and
concurrent execution.
\end{abstract}
