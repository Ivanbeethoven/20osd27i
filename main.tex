\author{Internal research draft\\26 October 2026}
\date{}
\maketitle
\begin{abstract}
Agents exploring alternatives from a common revision need private
working state and continued access to shared inputs. Sharing file
contents avoids duplication, but leaves the costs of constructing
private views, serving metadata, and fetching partial data.
\sys addresses these costs through three independently optional
mechanisms. Delta-Based Workspaces keep a shared immutable baseline and
store private namespace state and data-range mappings, preserving
references to unchanged data. Packed Metadata moves supported queries
for a selected, published read-only directory version into authenticated
object pages that co-locate names, attributes, and data locators. It
targets stable small-file collections reused across tasks, including
training inputs. Variable-Granularity Object Storage separates client
object formation from backend encoding and verification units to
control the work induced by partial reads. These choices incur distinct
preparation, access, and retention costs. We describe their
representations and update protocols, and characterize 1,138,884 FUSE
requests from eight coding-agent runs. The evaluation plan tests the
expected benefits in each mechanism's intended workload, then examines
fork, migration, and concurrent execution.
\end{abstract}
