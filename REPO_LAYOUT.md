# Repository layout

This repository contains the manuscript. Build root `main.tex`; chapters are in
`sections/`, with final publication figures in `figures/`. Bibliography, styles,
and `main.pdf` remain at the root. Compilation requires no experiment checkout.

Experiments, replay tools, analysis scripts, raw/derived observations and cloud
smoke records belong to `Ivanbeethoven/ax-multi-agent-experiments`. That repository
includes this repository as the `paper/` Git submodule, pinned to a paper commit.
There is no reverse submodule dependency.

Research/writing notes and source evidence remain in `planning/`, `evidence/`,
`references/`, `validation/`, and `skills/`. Older reports retain historical paths;
they do not define the current layout. Workload figures are regenerated by scripts
in the experiment repository and written to its `paper/figures/` checkout.
