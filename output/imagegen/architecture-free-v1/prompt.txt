① Shared snapshots + private deltas

② Packed Metadata
Inside the shared snapshot, immutable groups organize directory entries, common file attributes, and data locators together. Indexed name ranges lead to these grouped records; locators lead to authenticated file-data frames in stored objects. This is an access-oriented organization of shared metadata and content.

At finalized object upload, client policy can suggest an erasure-coding block size B. RustFS admits and persists the object's effective coding and verification geometry (B, q). Different objects can have different block layouts. Reads and repair use each object's saved layout. q is a verification unit inside a shard; packed frame, coding block B, and verification quantum q are distinct scales.
