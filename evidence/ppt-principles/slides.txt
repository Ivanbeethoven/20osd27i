Notes: FUSE 是内核与用户态文件系统之间的请求和应答接口。应用沿用文件调用，内核把到达该挂载的请求交给 ScorpioFS。研究记录操作类型、UID、请求字节、状态和处理时间。五个核心历史 profile 合计 269,995 条事件，权限参考线的 46,021 条另计。 | 页缓存命中可能绕过用户态，所以这是 FUSE 可见访问轮廓，不是应用的全部系统调用，也不是对象存储网络流量。模型、机器、UID、缓存和任务阶段并未完全受控，因此不将五组配置用于速度排名。研究使用固定快照，未独立重跑 Agent 或重新计算完整原始 trace。 | 来源： | - [CF01] Linux VFS 官方文档：https://docs.kernel.org/filesystems/vfs.html | - [CF02] Linux FUSE Overview：https://docs.kernel.org/filesystems/fuse/fuse.html#kernel-userspace-interface | - [CF03] Linux FUSE I/O Modes：https://docs.kernel.org/filesystems/fuse/fuse-io.html | - [TS04] ScorpioFS：统计脚本与操作计数 CSV：https://github.com/Ivanbeethoven/scorpiofs-agent-fs-telemetry/blob/74e36ba70172cc31d896452e45cfef7642ce1bbf/analyze_fuse_logs.py | - [TS01] ScorpioFS Agent FS Telemetry：固定核心统计快照：https://github.com/Ivanbeethoven/scorpiofs-agent-fs-telemetry/blob/74e36ba70172cc31d896452e45cfef7642ce1bbf/summary.json | - [TS02] ScorpioFS：核心历史任务与 Agent 行为分析：https://github.com/Ivanbeethoven/scorpiofs-agent-fs-telemetry/blob/74e36ba70172cc31d896452e45cfef7642ce1bbf/agent-fs-analysis.md | - [TS03] ScorpioFS：核心与诊断补测的分层汇总：https://github.com/Ivanbeethoven/scorpiofs-agent-fs-telemetry/blob/74e36ba70172cc31d896452e45cfef7642ce1bbf/aggregate-summary.md
