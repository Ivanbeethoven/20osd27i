\title{\sysname: Delta-Based Multi-Agent Workspaces with Packed Metadata\\
and Variable-Granularity Object Storage}
\author{Internal research draft\\22 October 2026}
\date{}
\maketitle
\begin{abstract}
Parallel coding agents can start from a common repository and dependency
environment while requiring independent file-system views. Reusing that
baseline raises three connected questions: how to represent private changes,
how to access shared metadata without repeated per-file database lookups, and
how to map partial object access to physical storage I/O. We present the design
of \sysname, which combines delta-based workspaces, packed immutable metadata,
and an interface for per-object storage layouts. A private writable upper
records namespace and data-mapping changes over a pinned snapshot. The shared
lower places directory entries, common attributes, and data locators in paged,
directory-oriented structures on object storage. Once an upload's final length
is known, a layout hint allows the backend to select and persist an encoding
block and a compatible verification/read quantum. We describe inspected
prototype components and identify the remaining integration gates. We also
specify an evaluation that separates layout effects from caching and request
coalescing, accounts for construction and recovery costs, and tests complete
agent tasks. The present draft reports no new performance results.
\end{abstract}
